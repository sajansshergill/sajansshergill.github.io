TrustPipe

TLC parquet · NOAA API · KafkacontractsSnowflake / BigQuerydbtstar schema

github.com/sajansshergill/trustpipe

Most portfolio pipelines prove you can move data. TrustPipe proves the data is correct: every source declares a contract, and a violation blocks the load instead of poisoning downstream tables. dbt tests and Great Expectations cover critical columns, and Isolation Forest plus ARIMA baselines catch silent volume and fare drift that schema checks miss.

Guarantee GitHub Actions runs the contract and test suites on every PR. A change that breaks a data guarantee cannot merge.

Payments · Streaming

Transaction Intelligence Pipeline

Real-time fraud signals and merchant analytics.

Kafka (AVRO)S3PySparkIcebergSnowflake

A Kafka producer publishes AVRO payment events partitioned by customer, with a dead-letter topic for malformed messages. PySpark checks every record against 10 named flags, quarantines failures, and builds velocity features with time-based windows. Snowflake loads a Kimball star schema via COPY INTO.

Guarantee Loads are idempotent on transaction_id; reruns never double-count.
