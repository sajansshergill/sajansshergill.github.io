Commission & Contract Data Quality Dashboard

A data cleaning and visualization project using Excel, Power BI & Python.

Project Overview

This project simulates a real-world financial operations scenario by cleaning, validating, and visualizing commission and contract data. The goal is to support strategic decisions through accurate metrics and an interactive dashboard.

Problem Statement

  • Missing commission percentages
  • Duplicate contract records
  • Inconsistent date formats
  • Mismatch between contract amount & commissions

Tools & Technologies Used

  • Excel (Advanced formulas, Pivot Tables)
  • Power BI (Dashboard Visuals)
  • Python (pandas for optional wrangling)
  • Google Sheets (Collaborative editing)

Dataset Fields

commission_data.csv: agent_id, contract_id, date, amount, commission_pct, region, commission

contract_data.csv: contract_id, start_date, end_date, client_name, total_value

Execution Steps

  1. Import & Inspect data
  2. Clean missing values, standardize formats, remove duplicates
  3. Validate commissions and contract values
  4. Calculate KPIs and insights
  5. Develop Power BI dashboard
  6. Highlight anomalies +/-15% from average

Visualizations

  • Bar chart: Total commission by region
  • Line chart: Monthly commission trends
  • Table: Contract validation summary
  • KPI cards: Total contracts and average commission percentage
